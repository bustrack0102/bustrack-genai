# guardrails

## Cuándo usar

Se trabaja en `specs/genai/guardrails/`.

## Pasos

1. Sanitizar entrada.
2. Detectar inyección.
3. Verificar grounding y fallar seguro.

## Prohibido

- Copiar patrones de otro stack sin adaptación.
- Declarar recursos o endpoints inexistentes.
- Introducir secretos o PII.
